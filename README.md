# IoT-Based Muscle Strain Detection & Alert System

## Overview

An IoT-based muscle strain monitoring system developed using an **ESP32 and EMG sensor** to monitor muscle electrical activity and detect abnormal variations in real time. The system processes EMG signals using the ESP32 ADC, classifies muscle activity into **Normal, Mild, and Abnormal** levels, activates a vibration motor and buzzer during abnormal activity, and uploads monitoring data to **ThingSpeak through Wi-Fi**.

## Features

* Real-time EMG signal acquisition using ESP32 ADC
* 12-bit ADC configuration with adjustable attenuation
* Moving-average filtering using **30 samples**
* ADC-to-millivolt conversion
* Variation-based muscle activity detection
* Three activity levels:

  * **Normal**
  * **Mild**
  * **Abnormal**
* 1-second persistence check for abnormal activity
* Vibration motor and buzzer alerts
* Wi-Fi connectivity
* Cloud monitoring using **ThingSpeak**
* HTTP GET-based data transmission
* Serial monitoring of EMG values and activity status

## Working

1. EMG electrodes capture electrical activity generated by muscle contraction.
2. The EMG sensor provides an analog signal to **GPIO 34**, configured as an ESP32 ADC input.
3. The ESP32 samples the signal and stores **30 samples** for moving-average filtering.
4. The filtered ADC value is converted into millivolts.
5. The firmware calculates the change (`Δ`) between the current and previous EMG readings.
6. Based on the variation, the system classifies activity as **NORMAL, MILD, or ABNORMAL**.
7. A variation above the abnormal threshold must persist for **1 second** before abnormal status is triggered.
8. During abnormal activity, the ESP32 activates both the **vibration motor and buzzer**.
9. EMG value, variation, and activity level are transmitted to **ThingSpeak using HTTP GET**.
10. The system repeats the monitoring and cloud-update process continuously.

## Detection Logic

```text
EMG Signal
    ↓
30-Sample Moving Average
    ↓
Convert ADC → mV
    ↓
Calculate Δ = |Current - Previous|
    ↓
┌───────────────────────────────┐
│ Δ < 10       → NORMAL         │
│ 10 ≤ Δ < 35  → MILD           │
│ Δ ≥ 35       → ABNORMAL*      │
└───────────────────────────────┘

* Abnormal condition must persist for 1 second
```

## ThingSpeak Data

The system sends three parameters to ThingSpeak:

| Field   | Data                    |
| ------- | ----------------------- |
| Field 1 | Filtered EMG value (mV) |
| Field 2 | EMG variation (Δ)       |
| Field 3 | Activity level          |

Activity levels are represented as:

```text
0 → NORMAL
1 → MILD
2 → ABNORMAL
```

## Running the Project

1. Install Arduino IDE and ESP32 board support.
2. Install the required ESP32 Wi-Fi and HTTP libraries.
3. Create a ThingSpeak channel with three fields.
4. Enter your Wi-Fi credentials and ThingSpeak API key in the code.
5. Upload the firmware to the ESP32.
6. Open Serial Monitor at **115200 baud**.
7. Monitor EMG values and activity classification.
8. View transmitted data on the ThingSpeak dashboard.
